# Project Overview

TRUVE는 뮤지컬 예매, 공연 정보 탐색, 배우와의 소통을 하나의 플랫폼으로 통합하는 서비스입니다.
본 레포는 TRUVE의 공정한 티켓팅을 위한 VQA/CAPTCHA 및 봇 탐지 모듈을 개발합니다.

## Goals

- 15,000석 규모 트래픽 폭주 상황에서 안정적으로 동작
- 매크로/다계정 등 비정상 접근을 능동적으로 차단
- VQA/마우스 퀴즈 기반의 공정한 인증 경험 제공

## Core Values

- 공정성: 동일한 조건에서 예매 기회를 보장
- 안정성: 대규모 동시성에서도 latency 제한
- 분리/확장: 모듈별 MSA 운영
