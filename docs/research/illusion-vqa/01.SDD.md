# VQA Bot Detection Module

Software Design Document (SDD)

## 목적

이 모듈은 티켓팅 플랫폼에서 자동화된 봇을 탐지하기 위한 VQA 기반
challenge 시스템을 제공한다.

## 핵심 전략

-   Visual Illusion 기반 시각적 혼란
-   Cognition 기반 추론 문제
-   Interaction telemetry 수집

## 기본 흐름

Security Layer → VQA Challenge → Post Evaluation → Allow / Retry / Escalate

## Challenge 유형

1.  Spatial Reasoning
2.  Conditional Counting
3.  Ordered Interaction

+ Arithmatic Reasoning 

## Escalation 정책

correct + normal → allow
correct + suspicious → mouse/touch quiz
wrong + normal → retry
wrong + suspicious → escalate
